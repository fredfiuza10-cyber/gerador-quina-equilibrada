# gerador-quina-equilibrada
Gerador de sequências para a Quina com filtros de equilíbrio (pares/ímpares e baixos/altos). Ideia e lógica do projeto: minhas. Código escrito com apoio de IA e adaptado por mim em etapas, pois ainda estou aprendendo a programar. Não aumenta a chance de ganhar: a Quina é aleatória. Projeto estritametne experimental
